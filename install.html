Android 用 Chrome

  1. 用 Chrome 打开上面的网址
    Open the link in Chrome · Buka pautan dalam Chrome
  2. 按右上角 ⋮
    Tap ⋮ at the top right · Tekan ⋮ di atas kanan
  3. 按「安装应用」或「添加到主屏幕」
    Tap Install app or Add to Home screen · Tekan Pasang aplikasi atau Tambah ke skrin utama
  4. 桌面出现 24 Xpress 图标，以后按它就开
    The 24 Xpress icon appears; open the App from it · Ikon 24 Xpress muncul; buka dari situ

iPhone 用 Safari

  1. 一定要用 Safari 打开上面的网址
    Must be Safari (not Chrome) · Mesti guna Safari
  2. 按下面中间的 分享 按钮（方框加向上箭头）
    Tap Share (square with an arrow) · Tekan Kongsi
  3. 往下拉，按「添加到主屏幕」，再按「添加」
    Scroll, tap Add to Home Screen, then Add · Tatal, tekan Tambah ke Skrin Utama, kemudian Tambah
  4. 从桌面图标打开，才收得到通知
    Open it from the icon to get notifications · Buka dari ikon untuk terima notifikasi

First login: enter the staff number or invite code on your slip, then set a PIN. After that, only the PIN. · Log masuk pertama: masukkan nombor pekerja atau kod jemputan pada slip, kemudian tetapkan PIN. Selepas itu, PIN sahaja.
