Obsidian + Claude Code 第二大脑

搭建指南 / Setup Guide · 约 5 分钟 / about 5 minutes

核心思路 / Core idea

第二大脑本质是一堆文本文件。你负责放入资料，AI 负责整理，你只需要阅读。
A second brain is just text files. You add sources, the AI organizes them, you read.

第 1 步：创建库 / Step 1: Create a vault

打开 Obsidian → 创建新库。
Open Obsidian → Create new vault.

第 2 步：用 Claude Code 打开 / Step 2: Open it in Claude Code

在库所在的文件夹里打开终端，然后运行：
Open a terminal in the vault folder, then run:

claude

第 3 步：放入模板 / Step 3: Add the template

把模板中的 CLAUDE.md、raw/、wiki/ 复制进库。
Copy CLAUDE.md, raw/ and wiki/ from the template into the vault.

库 / vault
├── CLAUDE.md      规则 / rules
├── raw/           原始素材（只读）/ sources (read-only)
└── wiki/          整理后的页面 / processed pages
    └── index.md   目录 / index

第 4 步：喂资料 / Step 4: Feed it

把文档拖进 raw/，然后对 Claude 说"处理这个"。wiki/ 里会出现双语页面，图谱视图里也会多出节点。
Drag a document into raw/ and tell Claude "process this". A bilingual page appears in wiki/, and new nodes show up in Graph view.

第 5 步：自动归档 / Step 5: Auto-filing

内容 / Output写到哪里 / Goes to
任务运行日志 / Run log今日日记 ## log / today's daily note
会议总结 / Meeting summary项目笔记 ## decisions / project note
研究资料 / Research## reading

Claude 只在这个标题下追加内容，文件其余部分保持不变。
Claude appends under that heading only; the rest of the file stays unchanged.

按标题写入需要 Obsidian 1.15 抢先体验版的 CLI，CLI 从 1.12 起内置（引自原帖，未核实）。确切命令请运行 obsidian help 查看。版本更早时，Claude 会直接编辑 .md 文件，效果相同。
Heading inserts need the Obsidian 1.15 early-access CLI; the CLI has been built in since 1.12 (claims from the source post, not verified). Run obsidian help for the exact commands. On older versions, Claude edits the .md files directly with the same result.
